# 功能说明

以下选项、默认值和判分规则来自 `V3.4.html` 的页面和逻辑。

上传页勾选的题库，是背题、搜题的范围，也是考试和练习设置里的默认勾选。功能选择页上的题数，同样只计已勾选题库。

## 模拟考试

设置项：

| 项 | 可选 | 默认 |
| --- | --- | --- |
| 题库 | 已导入的题库，可多选 | 上传页当前勾选的那些 |
| 及格线 | 0–100 的整数，单位是百分比 | 90 |
| 题目数量 | 10、20、50、100、全部 | 100 |
| 考试时长 | 30、60、90、120 分钟 | 60 |

只从客观题（单选、多选、判断）里抽。没有客观题时不能开始。数量小于题库时随机抽；数量大于题库时用全部，并提示题数不足。「全部」不打乱，按导入顺序。

考试中：

- 单选、判断点一个选项即替换。多选可以反复点选、取消，没有「至少选两项」的限制。
- 右侧（窄屏时在上方）有题目导航。已答和未答用颜色区分。点编号滚到该题。
- 倒计时剩余 10 分钟内变警告色，剩余 5 分钟内变危险色。时间到自动交卷。
- 主动交卷时，若还有未答题，会先确认。未答按错误处理。
- 退出考试会确认。确认后本次答题进度丢失，不计成绩，也不进错题本。

成绩：

- 大号数字是**答对题数**，不是百分制分数。旁边的「总分」是本次题数。
- 正确率 = 答对题数 / 本次题数 × 100。达到及格线为及格，否则不及格。
- 错题回顾列出答错和未答的题，并写入错题本。考试**不增加**「已练习次数」。练习次数只在练习模式提交时增加。

## 练习模式

| 项 | 可选 | 默认 |
| --- | --- | --- |
| 题目来源 | 题库题目、收藏题目、错题题目 | 题库题目 |
| 题库 | 来源为题库时可多选 | 上传页当前勾选的那些 |
| 练习顺序 | 见下表 | 未练随机 |
| 练习数量 | 10、20、25、50、100、150、200、全部 | 25 |
| 题型 | 单选、多选、判断，可多选 | 全选 |
| 答题模式 | 答对自动下一题、手动下一题 | 答对自动下一题 |

顺序：

| 名称 | 行为 |
| --- | --- |
| 顺序练习 | 保持来源里的顺序 |
| 随机顺序 | 打乱 |
| 智能随机 | 练习次数少的在前，相邻题有 30% 概率对调 |
| 未练题目 | 只留练习次数为 0 的题，保持原顺序。按钮上显示当前范围内的未练题数 |
| 未练随机 | 只留没练过的，再打乱。题数与「未练题目」相同 |

题数按当前来源、已选题库（来源为题库时）和已选题型计算，只计客观题里练习次数为 0 的题。切换来源、题库或题型时，两个按钮上的数字一起更新。

来源是收藏或错题时，不显示题库选择。收藏夹、错题本为空时不能从该来源开始。非客观题不会进入练习。

做题时：

- 多选至少选 2 项才能提交。没选会提示先选择答案。
- 提交后锁定选项，标出正确项；选错的项标红。
- 答对：显示「回答正确」。有解析时先藏起来，要点「查看解析」。若当前是自动模式，约 0.9 秒后进入下一题。
- 答错：立刻显示正确答案和解析，并写入错题本（同一题只保留最近一次你的答案）。
- 每次提交都给这道题的练习次数 +1。答错时错误次数也 +1。
- 可以上一题、从导航跳题。跳走再回来，已提交的题保持已判状态。
- 最后一题未提交时，不能结束练习，会提示先提交本题答案。
- 退出练习会确认。已提交的次数、错误次数和错题本保留；没提交的题不记。

结果页的大号数字是正确率（答对 / 本题量）。60% 及以上用通过色，低于 60% 用失败色，文字始终是「完成」。这和考试的及格线不是同一套规则。

结果页的错题回顾包含提交错误的题，以及跳过、没有提交的题。没提交的显示「未作答」，而且**不会**因为出现在这张回顾里就写入错题本。

## 背题模式

范围是已勾选题库的全部题型，包括简答等非客观题。进入页面时会按题库里实际出现的题型生成筛选，新出现的题型默认勾选。

排序：

- 题目顺序
- 练习次数少在前
- 错误次数多在前
- 随机排序

敏感词框用空格分隔多个词，题干和选项里的命中词会高亮。进入背题时，如果框是空的，会填入 `不 绝对 无需`。正在用中文输入法组字时不会中途打断。

客观题显示「正确答案」并高亮对应选项。其他题型显示「参考答案」，不把答案字母去对选项。

每题可以收藏。导航按单选、多选、判断着三种颜色；其他题型没有这三种颜色。

## 搜题模式

输入框：关键词用空格分开，必须**同时**命中（并且关系）。`*` 是通配，例如 `局麻*` 可以匹配「局麻药」。回车或点「搜索」开始。大小写不敏感。

范围可勾选：题干、选项、解析。题型筛选和背题一样，按题库里实际有的题型生成。

结果高亮关键词，标出来源题库，并可以收藏。没有匹配时提示更换关键词或调整范围。

## 收藏夹

在背题、搜题、练习里点收藏。同一题（同一个 ID）只保留一条。

收藏夹可以单条取消，也可以清空。清空前会确认，且不能恢复。

收藏的是题目副本。后来覆盖导入、改了题干，旧收藏不会自动更新；ID 变了就是另一道题。

## 错题本

写入时机：

- 练习里提交并且判错
- 考试交卷时判错或未答

同一题再次答错，只更新「你的答案」，不新增一条。答对**不会**自动把它从错题本移除。要消失，只能单条删除或清空。清空前会确认。

错题本可以当作练习来源，用来专练错过的题。

## 离开、刷新、返回

只在考试页或练习页、并且题目已经生成时拦截：

- 刷新或关闭：浏览器弹出离开确认。考试的提示是进度将丢失。练习的提示是未提交的进度将丢失，已提交的记录会保留。
- 浏览器后退，或地址栏哈希变到别的页：先用确认框询问。取消则留在当前页。确认则停表并离开，未交卷的考试进度丢掉。

直接点「退出考试」「退出练习」走的是页面内确认，不是浏览器那条提示。
