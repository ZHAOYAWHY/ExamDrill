# 介绍

ExamDrill 是一个客观题备考练习系统，当前发布版是 **3.3**。产品就是 Release 里的 `V3.3.html`：一个约 1 MB 的单文件，用浏览器打开即可。没有安装包，没有服务器，也没有账号。

本文依据 2026-11-06 发布的 [Release 3.3](https://github.com/ZHAOYAWHY/ExamDrill/releases/tag/3.3) 整理。

## 适合什么

已经有 Excel 题库，需要反复做单选、多选、判断的人。典型用法是资格考试、课程测验、单位内部题库这类客观题。

它不做这些事：

- 不批改简答、填空、论述。这类题可以导入并查看参考答案，但不进入练习和考试。
- 不提供题库内容。题库由使用者自己准备。
- 不同步到云端。换设备要自己导出同步字符串，并重新导入 Excel。
- 不是间隔重复（SRS）记忆软件。它记录练习次数和错误次数，用来排序和筛选，没有复习日程。

## 页面结构

打开后先是上传页。至少成功导入一个题库，才能进入功能选择。

顶栏始终有两个按钮：

- **视觉风格**：清新简洁、活力多彩、拟物卡片，循环切换。
- **亮色 / 暗色**：默认暗色。第一次用 3.3 打开时会写成暗色；之后可以自己改，选择会记住。

功能选择页有六个入口，外加导出同步数据、导入同步数据、返回上传。

| 入口 | 页面上的说明 |
| --- | --- |
| 模拟考试 | 限时答题，检验学习成果 |
| 练习模式 | 专项练习，即时反馈 |
| 背题模式 | 浏览全部题目与解析 |
| 搜题模式 | 关键词搜索，快速定位 |
| 收藏夹 | 管理收藏的重点题目 |
| 错题本 | 集中复习答错的题目 |

背题、收藏夹、错题本的卡片上会显示当前数量。数量只统计上传页里勾选的题库；取消勾选某个题库后，背题和搜题里就看不到它，考试和练习的题库列表里也不会默认带上它。

## 技术上它是什么

- HTML + CSS + 原生 JavaScript，没有前端框架。
- [SheetJS](https://sheetjs.com/) 的 `xlsx.js` 已内嵌，用来读 `.xlsx` / `.xls`。
- 数据写在浏览器 LocalStorage，前缀是 `qb3.`。
- 题目 ID 是内容的 MD5。参与计算的是题型、题干、选项、答案、解析。章节、难度、文件名不参与。所以同一道题换文件、调整行序，ID 不变。

仓库的 Code 页不包含这个 HTML。要运行，请下载 Release 附件，不要把 README 当成程序。
