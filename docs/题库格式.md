# 题库格式

3.3 只按**模板二**解析。页面上的格式说明也只写这一种。2.1.8 提到过两种 Excel 格式，不要拿那种旧表直接套 3.3 的预期；表头对得上下面的规则时，3.3 才能导入。

## 文件

- 扩展名：`.xlsx` 或 `.xls`。
- 第一行必须是表头。没有表头、或只有一行，会报「文件内容为空」。
- 多个工作表时，选**行数最多**的一张。说明页、版本页请保持比题目表短。
- 题库名 = 文件名去掉扩展名。与表内任何列无关。

## 表头怎么认

比较前会去掉空格、中英文括号、中英文标点，并转成小写。所以下面这些都能认成题干列：

- `题干`
- `题干(必填)`
- `题干（必填）`
- `题目`

必填列用**前缀**匹配：

| 用途 | 接受的开头 |
| --- | --- |
| 题干 | `题干`、`题目` |
| 题型 | `题型`、`类型` |
| 答案 | `正确答案`、`标准答案`、`答案` |
| 解析 | `解析` |
| 章节 | `章节` |
| 难度 | `难度` |

缺题干、题型或答案列时，提示表头格式不正确。找不到任何选项列时，提示未找到选项列。

选项列接受：

- `选项A` … `选项H`，可以写成 `选项 A`、`选项E(勿删)`
- `选项1` … `选项8`，会按 A–H 对应
- 单独一个字母 `A` … `H`

选项按字母排序后读取。单元格空的选项会被丢掉，所以一道题可以只用 A–D，E–H 留空。

推荐表头，和软件里写的一致：

```text
题干 | 题型 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 选项G | 选项H | 正确答案 | 解析 | 章节 | 难度
```

列顺序可以打乱。多出来的、认不出来的列会被忽略。

## 题型

单元格里的写法会先规范化：

| 填写 | 当成 |
| --- | --- |
| 单选、选择题 | 单选题 |
| 多选 | 多选题 |
| 判断、判断题、对错 | 判断题 |
| 其他非空文字，如简答、填空 | 保持原文，当作非客观题 |

题干为空，或题型为空的行会跳过。

非客观题会导入，并计入题库题数。背题、搜题的题型筛选里会出现它们。练习和考试会排除它们。导入成功后如果有这类题，会弹出提示。

## 答案

比较前会把全角英文字母转成半角，再转成大写。`ａ`、`Ａ`、`a` 都按 `A` 判。

### 单选

写一个选项字母，如 `A`。页面按这个字母高亮对应选项。

### 多选

下面这些都会收成按字母排序的 `AC`：

- `AC`
- `A、C`
- `A，C`
- `A,C`
- `A C`
- `CA`

分隔符可以是顿号、中英文逗号、分号或空白。练习里提交多选时至少要选 2 项；考试里没有这个限制，但判分要求选项集合完全一致，多选、少选都算错。

### 判断

导入时把答案收成 `A` 或 `B`：

| 写成这些 | 记成 |
| --- | --- |
| 正确、TRUE、T、对、是、√、V、A | A |
| 错误、FALSE、F、错、否、×、X、B | B |

如果判断题的选项不足两项，软件会补上「A 正确」「B 错误」。页面上的「正确答案」显示的是规范化之后的 `A` 或 `B`，选项文字仍是「正确 / 错误」。

大小写不敏感。`true` 会先被转成 `TRUE` 再识别。

## 解析、章节、难度

这三列可选。

- 解析会在背题、搜题、收藏、错题，以及练习答错、考试错题回顾里显示。答对练习时解析默认折起，要点「查看解析」。
- 章节和难度会随题目保存，**当前界面不展示这两列**。它们也不参与题目 ID。只改章节或难度、再覆盖导入，统计和收藏仍然对得上。

## 题目 ID

ID 由题型、题干、选项（字母和文字）、答案、解析拼起来做 MD5。

因此：

- 改行序、改文件名、改章节、改难度：ID 不变。
- 改题干、选项、答案、解析或题型：这是另一道题，旧的练习次数不会自动迁过去。

覆盖同名文件时，整本替换。旧统计按 ID 保留；内容变过的题，旧统计会留在本地，但不再挂到新题上。

## 一份最小示例

| 题干 | 题型 | 选项A | 选项B | 选项C | 选项D | 正确答案 | 解析 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 麻黄碱是 | 单选 | 直接作用药 | 间接作用药 | 混合作用药 | 以上都不是 | C | 兼有直接和间接作用 |
| 下列属于局麻药的是 | 多选 | 利多卡因 | 布比卡因 | 多巴胺 | 罗哌卡因 | A、B、D | |
| 普鲁卡因属于酯类局麻药 | 判断 | | | | | 正确 | |

第三行没有选项也行，导入后会变成 A 正确 / B 错误。
