# ExamDrill

单文件、离线的客观题备考练习系统。下载一个 HTML，用浏览器打开，导入 Excel 题库即可开始。不安装、不注册、不联网。

**当前版本 3.3。** 下面的说明依据 [Release 3.3](https://github.com/ZHAOYAWHY/ExamDrill/releases/tag/3.3) 里的 `V3.3.html`，不是更早的 2.1.8。

[下载 V3.3.html](https://github.com/ZHAOYAWHY/ExamDrill/releases/download/3.3/V3.3.html) · [全部版本](https://github.com/ZHAOYAWHY/ExamDrill/releases) · [使用说明](docs/)

可运行文件在 Releases 里。这个仓库只放说明、许可证和 Issue 模板，没有需要编译的源码工程。

## 能做什么

面向单选、多选、判断。简答题等其他题型可以导入，在背题和搜题里查看，不进入练习和考试。

| 模式 | 做什么 |
| --- | --- |
| 模拟考试 | 从题库抽题，限时作答，到点自动交卷，按及格线判定 |
| 练习模式 | 按来源、顺序、题量和题型练习，提交后立刻判分 |
| 背题模式 | 浏览题干、答案和解析，可按练习情况排序，也可高亮敏感词 |
| 搜题模式 | 在题干、选项、解析里按关键词查找，`*` 可作通配 |
| 收藏夹 | 收藏重点题，也可以把收藏夹当作练习来源 |
| 错题本 | 考试交卷后答错的题、练习里提交错误的题，会记在这里 |

同一份页面里可以加载多个题库。文件名（去掉扩展名）就是题库名。

## 怎么开始

1. 下载 [V3.3.html](https://github.com/ZHAOYAWHY/ExamDrill/releases/download/3.3/V3.3.html)（约 1 MB）。Excel 解析已经打进这个文件，打开后不必再加载外部脚本。
2. 用系统浏览器直接打开。Chrome、Edge、Firefox、Safari 都可以。不要把文件拖进会把 HTML 当纯文本的编辑器。
3. 准备一份模板二的 `.xlsx` 或 `.xls`，拖进上传区，或点击上传区选择文件。
4. 进入功能选择，再选考试、练习、背题或搜题。

表头要能认出「题干」「题型」「正确答案」，并带有选项列。列顺序可以打乱，表头里可以带「(必填)」「(勿删)」这类备注。完整规则见 [题库格式](docs/题库格式.md)。

手机或窄窗口也能用。宽度不足时，题目导航会移到内容上方，顶栏只保留图标。

## 这一版的行为

这些是 3.3 相对仓库里上一版 2.1.8 的变化，以及 3.3 自己修过的点：

- Excel 解析内嵌，完全离线。
- 三套视觉主题：清新简洁、活力多彩、拟物卡片。每套都有亮色和暗色，默认暗色。选择会记在本机。
- 题目按内容生成稳定 ID。统计、收藏、错题不随排序或文件名变化；同一道题出现在不同文件里，记录仍然对得上。
- 全角字母答案（如 `Ａ`）会先转成半角再判分。
- 考试题量只能从列表选择：10、20、50、100 或全部。不能手填任意数字。
- 考试或练习进行中，刷新、关闭页面，或用浏览器返回，会先提示。已经提交过的练习次数、错误次数和错题本会保留；没交卷的考试进度不会保留。
- 练习的最后一题还没提交时，不能结束练习。

## 数据放在哪

题库、统计、收藏、错题和主题都在当前浏览器的 LocalStorage 里，键名以 `qb3.` 开头。换浏览器、换设备，或清掉这个文件对应的站点数据，记录就没了。

功能选择页可以导出、导入一段同步字符串。它只搬练习统计、收藏和错题，不包含题库文件。两边要先导入同名、内容一致的题库，才能对上。详见 [数据与同步](docs/数据与同步.md)。
