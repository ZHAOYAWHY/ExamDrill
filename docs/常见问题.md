# 常见问题

针对 `V3.4.html`。如果用的是 2.1.8 或 3.3，先换到 [3.4](https://github.com/ZHAOYAWHY/ExamDrill/releases/download/3.4/V3.4.html) 再对照。

## 打开后是一堆代码

浏览器没有把它当网页。换 Chrome 或 Edge，对文件选「打开方式」，不要用记事本或 VS Code 的预览当正式入口。文件约 1 MB，因为 Excel 解析库在里面，这是正常的。

## 提示表头格式不正确

第一行必须能认出题干、题型、正确答案三列。列名可以是「题干(必填)」这种带备注的写法，但不能叫「问题内容」「question」这类对不上前缀的名字。

还需要至少一列选项，表头形如 `选项A` 或单独的 `A`。详见 [题库格式](题库格式.md)。

## 提示未解析到有效题目

表头过了，但没有同时具备题干和题型的数据行。空行会被跳过。题型列空着也会跳过。

## 导入的题数比表格行数少

减去表头之后，题干为空或题型为空的行不计入。非客观题会计入，并额外提示它们不参与练习和考试。

## 工作簿里有题目，却说格式不对

多表时用的是**行数最多**的工作表。如果说明页、目录页比题目表还长，会被误当成数据表。把题目表做成行数最多的一张，或删掉更长的说明表。

## 判断题答案显示成 A / B

这是导入时的规范化结果。`正确`、`对`、`T`、`√` 记为 A，`错误`、`错`、`F`、`×` 记为 B。选项文字仍是「正确」「错误」。判分按 A/B，不按「正确」这两个字。

## 全角字母以前判错，现在呢

自 3.3 起会把 `Ａ`–`Ｚ`、`ａ`–`ｚ` 转成半角再比较。题库里写成全角 `Ａ`，作答点选 `A`，应判对。3.4 同样如此。

## 多选题选了一个，练习不能提交

练习要求多选至少 2 项。考试没有这条限制，但少选、多选都算错，必须和标准答案的字母集合完全一致。

## 考试分数看起来不像百分制

结果页大号数字是答对题数。「总分」是本次题数。及格与否用正确率对比及格线，默认及格线 90%。100 题对了 90 题，大号数字是 90，状态是及格。

练习结果页的大号数字才是百分比。那里的颜色以 60% 为界，和考试及格线无关。

## 考试做错了，背题里的「已练习」没增加

考试只把错题写入错题本，不增加练习次数。练习次数只在练习模式点「提交答案」时增加。

## 答对了，错题本里还有这道题

答对不会自动移出错题本。需要的话在错题本里删除，或清空后重新积累。

## 删了题库，收藏和错题还在

删除题库会清练习统计，不会清收藏夹和错题本里的副本。这是 3.4 的实际行为，3.3 也一样。

## 换了浏览器，记录没了

记录不在 HTML 文件里，在浏览器 LocalStorage 里。换浏览器、换电脑、开无痕、清站点数据，都会看不到旧记录。用功能选择页的同步字符串搬进度，题库 Excel 要在新浏览器里重新导入，且文件名和内容都要一致。见 [数据与同步](数据与同步.md)。

## 同步提示没有匹配的题库

常见原因：

- 新设备还没导入 Excel。
- 文件名不同。`题库.xlsx` 和 `题库-新.xlsx` 是两个名字。
- 内容有差别，整本校验和不一致。多一行、改一个字，都会跳过这一本。
- 粘贴时多了空格或少了一截。

## 刷新以后考试没了

这是预期行为。考试进行中刷新、关闭或返回，会提示进度将丢失。没有交卷的答案不会保存。练习里已经点过提交的题，次数和错题本还在。

## 最后一题做完了，却不能结束

最后一题要先点「提交答案」。只选了选项、没提交，不能结束。

## 背题里突然高亮了「不」「绝对」「无需」

进入背题时，敏感词框如果是空的，会填上这三个词，用来标出绝对化表述。不想要就删掉，或改成自己的词，空格分隔。

## 章节和难度导入了，页面上没有

3.4 会保存这两列，界面不展示。它们不影响题目 ID，也不参与判分。

## 能不能多人同时用一个文件

可以各自下载同一份 HTML。记录各自留在自己的浏览器里，不会互相覆盖。没有实时共享。
