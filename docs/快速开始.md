# 快速开始

对应文件：[V3.3.html](https://github.com/ZHAOYAWHY/ExamDrill/releases/download/3.3/V3.3.html)。不要用 2.1.8 对照下面的步骤，那一版的表格格式和离线方式不同。

## 1. 下载并打开

从 [Release 3.3](https://github.com/ZHAOYAWHY/ExamDrill/releases/tag/3.3) 下载 `V3.3.html`，用浏览器打开。

- 双击通常会用默认浏览器打开。
- 也可以把文件拖进浏览器窗口。
- 文件可以放在任意文件夹，也可以从网盘同步盘打开。它不访问网络。
- 用 `file://` 打开即可。不必搭本地服务器。

如果浏览器把页面显示成一堆代码，说明它被当成了文本。换一个浏览器打开，或在文件上选「打开方式」。

## 2. 准备题库

只接受 `.xlsx` 和 `.xls`。页面写明的是**模板二**：第一行是表头，一共可以有 14 列。

最少要有这几列，列名用前缀识别，顺序不限：

| 列 | 表头示例 | 必填 |
| --- | --- | --- |
| 题干 | 题干、题目、题干(必填) | 是 |
| 题型 | 题型、类型 | 是 |
| 选项 | 选项A … 选项H | 至少要有选项列；判断题选项可以空 |
| 正确答案 | 正确答案、标准答案、答案 | 是 |
| 解析 | 解析 | 否 |
| 章节 | 章节 | 否 |
| 难度 | 难度 | 否 |

文件名去掉扩展名后成为题库名。`麻醉学-第一章.xlsx` 会得到题库「麻醉学-第一章」。同名题库再次导入时会询问是否覆盖。

工作簿里有多个工作表时，自动选用行数最多的那一张，用来跳过「版本号」之类的说明表。

列的细节、判断题和多选题的答案写法见 [题库格式](题库格式.md)。

## 3. 导入

在上传页把文件拖进虚线区域，或点击该区域选择文件。

成功后会提示题库名和题数。如果里面有简答等非客观题，会再提示：这些题只供查看，不参与练习和考试。

上传页下方列出已加载的题库：

- 勾选框决定这个题库是否参与后续的背题、搜题，以及考试/练习设置里的默认选中。
- 垃圾桶删除该题库，并清掉这些题目的练习统计。收藏夹和错题本里已经抄进去的题目副本不会跟着删。

题数为 0 时，「进入功能选择」是灰的。

## 4. 选一个模式

导入成功后点「进入功能选择」。

想马上做题：进练习模式。默认来源是题库，顺序是「未练随机」，数量 25 题，题型全选，答对后自动下一题。

想先看答案：进背题模式。进入时如果敏感词框是空的，会填上 `不 绝对 无需`，用来高亮绝对化表述。可以改掉。

## 5. 换电脑之前

在功能选择页点「导出同步数据」，复制弹窗里的字符串，自己存好。

新电脑上先导入**同一份** Excel（文件名也要一致），再点「导入同步数据」，粘贴那段字符串。对不上的题库会被跳过。见 [数据与同步](数据与同步.md)。
