# 版本说明

仓库里公开发布过三个版本。当前应使用 **3.4**。

| 版本 | 发布时间 | 附件 | 说明 |
| --- | --- | --- | --- |
| [3.4](https://github.com/ZHAOYAWHY/ExamDrill/releases/tag/3.4) | 2026-11-07 | `V3.4.html` | 当前版。本文档按这个文件编写 |
| [3.3](https://github.com/ZHAOYAWHY/ExamDrill/releases/tag/3.3) | 2026-11-06 | `V3.3.html` | 上一版。练习设置没有未练题数，选项说明可能和标题挤在一行 |
| [2.1.8](https://github.com/ZHAOYAWHY/ExamDrill/releases/tag/2.1.8) | 2026-06-22 | `V2.1.8.html` | 更早一版。保留作对照，不要和 3.4 的表格说明混用 |

不同文件名互不升级。浏览器按文件地址隔离 LocalStorage，打开 `V3.4.html` 不会自动读到 `V3.3.html` 或 `V2.1.8.html` 里的记录。要沿用进度，用新文件重新导入题库，再导入同步字符串。3.4 与 3.3 的同步字符串结构相同（`version: 1`，含题库校验和、统计、收藏 ID、错题 ID），可以互导。2.1.8 的同步字符串不保证能被 3.4 导入。用 3.4 覆盖原来的文件地址时，同一浏览器里的记录会留在原地。

## 3.4 发布说明

来自 Release 正文，没有增删：

单文件离线版。下载 `V3.4.html` 后用浏览器直接打开，无需安装、无需联网。

相对 3.3：

- 选项按钮的标题和说明改为上下分行，不再挤在同一行
- 「未练题目」和「未练随机」显示当前范围内还没练过的题数。范围随题目来源、已选题库和题型变化

存储键与 3.3 相同。换文件名打开时，进度不会自动带过来。

## 3.3 发布说明

来自 Release 正文，没有增删：

单文件离线版。下载 `V3.3.html` 后用浏览器直接打开，无需安装、无需联网。

相对 GitHub 上的 2.1.8：

- Excel 解析已内嵌，完全离线
- 三套视觉主题，支持亮色 / 暗色
- 题目按内容生成稳定 ID，统计、收藏、错题不随排序变化
- 简答题等非客观题可导入查看，不进入练习和考试

V3.3 修正：

- 全角字母答案可正确判分
- 考试题量只能从列表选择
- 考试或练习中刷新、关闭、返回会提示；已提交的练习记录仍保留
- 最后一题未提交不能结束练习

## 2.1.8 发布说明

同样来自 Release 正文：

1. 多题库导入功能、2 种 Excel 题库格式
2. 离线同步练习进度功能
3. 背题 + 搜题 + 练习 + 模拟考试 + 收藏夹 + 错题本功能

3.4 的上传页只描述模板二，3.3 也是。不要假设 2.1.8 的另一种表还能按旧说明导入 3.4；以 [题库格式](题库格式.md) 为准。

## 文件内部的版本痕迹

`V3.4.html` 的样式注释仍写着「V3.0 三主题设计系统」，脚本注释写着「V3.4 应用逻辑」。存储里还有一次 `uiVer < 2` 的迁移，把默认主题改成暗色。这些不是单独发布的版本，没有对应的 Release。对外版本只看 Release 标签。
