# 数据与同步

3.3 没有账号，也没有服务器。所有数据都在**打开这个 HTML 的那个浏览器**里。

## 存在哪里

LocalStorage，前缀 `qb3.`：

| 键 | 内容 |
| --- | --- |
| `qb3.banks` | 已导入的题库。值是「题库名 → 题目数组」 |
| `qb3.sel` | 上传页勾选的题库名 |
| `qb3.stats` | 练习统计。值是「题目 ID → { p: 练习次数, w: 错误次数 }」 |
| `qb3.favs` | 收藏的题目副本 |
| `qb3.wrong` | 错题副本，含最近一次你的答案 |
| `qb3.ui` | 主题：`style` 为 `simple` / `vivid` / `apple`，`dark` 为是否暗色 |
| `qb3.uiVer` | 主题迁移标记。小于 2 时会把暗色设为开，并写成 2。用来让旧的默认亮色改成默认暗色，只做一次 |

空间不够时，保存会失败，并提示本地存储空间不足。浏览器对 LocalStorage 通常有数 MB 上限。题库很大时，优先减少一次导入的本数，或换一个存储更宽裕的浏览器配置。

这些数据跟「文件放在哪个文件夹」无关，跟「用哪个浏览器打开这个文件」有关。用 Edge 打开和用 Chrome 打开，是两套记录。同一浏览器的普通窗口和无痕窗口也是两套。

清除站点数据、清除 `file://` 数据，或重置浏览器，记录会消失。软件里没有云备份。

## 删除和覆盖时会怎样

删除题库：

- 删掉这本题库，并取消勾选。
- 删掉这些题目 ID 上的练习统计。
- **不**删除收藏夹和错题本里已经复制出去的题目。那些列表里仍能看到，也可以拿来练习。

覆盖同名文件：

- 整本替换成新解析结果。
- 内容没变的题，ID 不变，统计、收藏、错题还在。
- 题干、选项、答案、解析或题型变了的题，ID 改变，旧统计不会跟着走。

## 同步字符串

功能选择页的「导出同步数据」「导入同步数据」用来在两台设备之间搬**进度**，不搬题库文件。

导出前必须已经有题库。点导出后弹出一段文本，点「复制」会尝试写入剪贴板。剪贴板权限被拦时，可以在文本框里自己全选复制。

字符串是这段 JSON 的 Base64（UTF-8）：

```json
{
  "version": 1,
  "banks": { "题库名": "该题库题目数组的 MD5" },
  "stats": { "题目ID": { "p": 1, "w": 0 } },
  "favs": ["题目ID"],
  "wrongs": ["题目ID"]
}
```

`banks` 里只有名字和内容校验和，没有题目正文。

导入规则：

1. 字符串无法解码，或缺少 `banks` / `stats`，直接失败。
2. 按题库名匹配。本地没有这个名字，提示需要先上传该题库，并跳过。
3. 名字相同但内容 MD5 不同，提示内容不一致，并跳过。覆盖导入之后哪怕只改了一道题，整本的 MD5 也会变，这一本就不会同步。
4. 名字和内容都一致的题库，才参与合并。
5. 统计按题目 ID 取练习次数、错误次数的较大值，不会用较小的一边覆盖较大的一边。
6. 收藏和错题只**新增**本地还没有的 ID。不会删除本地多出来的收藏或错题，也不会用对方的作答覆盖你已有的错题记录。
7. 主题、勾选状态、考试设置不在同步字符串里。

所以正确的换机顺序是：

1. 旧设备导出字符串并保存。
2. 新设备用浏览器打开同一个 `V3.3.html`。
3. 导入**同名、内容相同**的 Excel。
4. 再导入同步字符串。

只复制 HTML、不复制 Excel，新设备上没有题可做，同步也会因没有匹配题库而失败。

## 题目 ID 和统计为什么还在

ID 不看文件名、行号、章节、难度。把同一张表另存成另一个文件名再导入，会得到另一个题库名，但题目 ID 相同。练习次数仍然认这些 ID。

两本题库包含同一道题时，统计是共享的。删除其中一本，会按那一本里的 ID 删统计；如果另一本还有同一 ID，统计也会被删掉。收藏副本不受删除题库影响。
